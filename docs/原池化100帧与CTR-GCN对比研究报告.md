# 原池化100帧与论文版单流 CTR-GCN 对比研究报告

## 摘要

原池化模型现作为项目 canonical baseline，在 NTU60 XSub 上完成100轮训练，输入为100帧置信度加权全序列压缩。统一评估 Top-1 为 **94.6400%**，Top-5 为 **99.5891%**，最佳 checkpoint 为第98轮。论文版单流 Joint CTR-GCN 使用100帧窗口、Joint stream、`unit_ctrgcn + mstcn`、65→27→11 progressive graph mapping，24个逻辑 epoch × 5次训练集重复，最佳验证 Top-1 为 **95.4802%**，Top-5 为 **99.6688%**。单流模型当前验证领先0.8402个百分点，但10-clip独立测试仍在服务器运行，因此该差异不是最终测试结论。

## 1 研究问题与比较范围

本研究比较原池化100帧/100轮模型与论文版单流 Joint CTR-GCN。两者都使用 RTMW 派生的二维骨架输入、100帧时间窗口、随机初始化和强制 `torch.compile`，但训练遍历数、batch size、图映射和读出协议不同。因此本文报告的是当前协议下的工程对比，不把精度差异归因于单一结构因素。

## 2 数据集与骨架输入

实验采用 NTU RGB+D 60 的 XSub 划分，训练样本39,627条，验证样本16,306条，60个动作类别，最多保留两个人物。原池化模型使用身体22点、左右手各21点和面部 token；论文版单流 CTR-GCN 使用 Joint stream，输入通道为 x/y/score，并通过 progressive graph mapping 将65点映射到27点和11点。

## 3 两类模型结构

| 维度 | 原池化100帧 | 论文版单流 Joint CTR-GCN |
|---|---|---|
| 输入 | RTMW-133二维；身体/双手/面部区域 | RTMW派生 SkeleT 输入；Joint stream |
| 图结构 | 身体22点 + 左右手21点 + 面部token | 65 → 27 → 11 progressive mapping |
| 骨干 | 分支化 CTR-GCN + 局部时空模块 | 10阶段 `unit_ctrgcn + mstcn` |
| 时间输入 | 100帧置信度加权全序列压缩 | 100帧 Joint stream |
| 训练计划 | 100轮，单周期 cosine | 24逻辑epoch × repeat 5，等效120遍历 |
| 参数量 | 1,115,716 | 约1,447,550 |

图结构页已逐节点标注：身体节点采用 RTMW 索引与语义名，双手采用 L0–L20 / R0–R20，并给出左右手对应的 RTMW 全身索引。

## 4 实验协议与可复现性

原池化训练使用 batch size 32、seed 1、5轮 warmup 加单周期 cosine。单流 CTR-GCN 使用 batch size 128训练、32验证、seed 1、Inductor fullgraph 编译，24个逻辑 epoch 每个重复5次训练集。两组配置均要求编译成功，禁止静默回退到整模型 eager；单流模型的10-clip独立评估正在服务器运行。

## 7 与公开 CTR-GCN 结果的关系

CTR-GCN 原论文常见的92.4%对应 Kinect 三维25点和多流设置。本项目论文版单流模型使用 RTMW 派生输入与 Joint stream，属于论文配置迁移，不是官方四流结果复现。原池化与单流 CTR-GCN 的当前差异不能直接写成官方方法的公平排名。

## 8 讨论、局限与后续实验

当前结果显示，论文版单流 Joint CTR-GCN 在训练验证记录上高于原池化100帧。限制包括：两者的训练遍历数不完全相同，读出协议和 batch size 不同，主要结果来自单一随机种子，单流10-clip测试尚未完成。

后续实验：

1. 完成单流 CTR-GCN 10-clip 独立评估；
2. 统一100帧输入、训练遍历预算、batch size和学习率计划；
3. 使用至少3个随机种子报告均值和标准差；
4. 进行身体、双手、面部及时间段遮挡实验。

## 9 结论

原池化100帧/100轮模型统一评估为94.6400% Top-1；论文版单流 Joint CTR-GCN 当前最佳验证为95.4802% Top-1。单流验证领先0.8402个百分点，参数量约为原池化的1.30倍。正式结论仍需等待10-clip测试，并在统一训练预算和多种子条件下复核。
