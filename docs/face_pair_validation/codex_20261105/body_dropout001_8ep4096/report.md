# 身体点 dropout 0.01 的短训配对研究

目标是在 0.005 与 0.02 之间测试 clean 与缺失鲁棒性的权衡。模型以 seed 17 随机初始化、强制 `torch.compile`/Inductor，训练 8 epoch、4096 样本、batch 32、warmup 1、head/fusion loss 0.5/1.0；相对对照只有身体点 dropout 从 0 改为 0.01，输出目录不同。使用预先固定的 epoch 8 `last.pt`，没有根据 γ=1 的验证结果选择 checkpoint；epoch 8 恰好也是各自硬路由最佳 epoch。拟合/校准/验证成员分别为 3745/351/4096，与对照完全一致。

两个冻结模型在同一输入张量及帧掩码上推理，各自从训练内校准计数形成 γ=1 HF/BF 原准确率比例权重。与 0.005、0.02 试验比较时，clean、5% 和 10% 条件的完整输入及 mask SHA 均逐项一致。校准样本相同但 60 类有 38 类权重不同，平均绝对差 0.1497、最大 1.0；差异反映训练及校准权重的共同影响。

| 输入条件 | 对照 γ=1 Top-1 | 0.01 候选 γ=1 Top-1 | 候选减对照 | 配对 bootstrap 95% CI（pp） |
|---|---:|---:|---:|---:|
| clean | 2347/4096 = 57.2998% | 2271/4096 = 55.4443% | -1.8555pp | [-3.1250, -0.5615] |
| 身体点缺失 5% | 1777/4096 = 43.3838% | 2233/4096 = 54.5166% | +11.1328pp | [9.6680, 12.5977] |
| 身体点缺失 10% | 1248/4096 = 30.4688% | 2055/4096 = 50.1709% | +19.7021pp | [18.1641, 21.2158] |

与各自 clean 比较，5% 缺失的下降量减少 12.9883pp（配对差中差 95% CI [11.4258, 14.5020]），10% 缺失的下降量减少 21.5576pp（CI [19.7998, 23.2910]）。配对 bootstrap 以验证样本为单位重采样 20000 次。按样本中的被试编号分组，4096 条样本覆盖 11 人；两个缺失条件均 11/11 人净增，clean 则 4 人净增、7 人净减。

| 训练时身体点 dropout | clean | 5% 缺失 | 10% 缺失 |
|---:|---:|---:|---:|
| 0 | 57.2998% | 43.3838% | 30.4688% |
| 0.005 | 55.4688% | 51.2207% | 42.0654% |
| 0.01 | 55.4443% | 54.5166% | 50.1709% |
| 0.02 | 53.8086% | 54.1260% | 50.5371% |

严格依据上述三个观测指标，四组都没有被另一组在全部指标上支配。0.01 比 0.005 clean 少 1 条（-0.0244pp，CI [-1.2695, 1.2207]），5%/10% 缺失下分别高 3.2959pp（CI [1.9775, 4.6143]）和 8.1055pp（CI [6.7139, 9.4727]）。0.01 比 0.02 clean 高 1.6357pp（CI [0.4395, 2.8320]），5%/10% 缺失差异分别 +0.3906/-0.3662pp，CI 均跨零。这些跨候选区间同样是验证样本配对区间，不涵盖训练随机性；四组为未收敛的 8 epoch 模型，不能据此声称完整训练会获得同等提升。

训练 completed、未出现 NaN/Inf；身体/手部编码、masked pooling、两分类头与融合使用 Inductor，原 face LocalSTBlock 的 eager 边界保留。候选 checkpoint SHA-256 为 `475bf610c7fe05d1800700fd5d0c3295ee9c35c956049450f38e3df6a1c1eaa1`，对照为 `8a0fc6d2ad19ceefc3fe3cfced748d67422fe9b46da86e508df86b3e3d26ea57`。本目录保存配置、状态、逐轮记录、训练与评估日志、划分清单、评估摘要和逐样本预测。配对代码为 [compare_face_pair_corruption.py](../../../../tools/compare_face_pair_corruption.py)；跨强度比较由 `compare_strengths.py` 从归档逐样本结果重算，输出 `strength_comparisons.json`。
