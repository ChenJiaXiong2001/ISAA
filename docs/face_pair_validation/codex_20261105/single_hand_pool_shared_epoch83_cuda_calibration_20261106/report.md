# 单手有效数归一化：训练校准筛选

## 结论

固定原模型 checkpoint 的推理实验不支持采用此候选：左手全程遮挡时，融合正确数从 2748 降至 2612，下降 136/3191（4.262 个百分点）；干净条件也减少 2 个正确样本。短时遮挡没有一致改善。该结果只说明冻结分类头下的表现，不能推断重新训练此结构后的表现。

训练校准集包含 P009 的 708 个样本和 P018 的 2483 个样本，共 3191 个；不存在 20 名校准主体。其标签曾用于计算 checkpoint 的融合权重，因此这是候选筛选而非独立泛化验证。未使用官方验证集选择候选。
