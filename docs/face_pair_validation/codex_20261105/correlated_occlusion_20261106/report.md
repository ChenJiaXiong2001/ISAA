# 同侧身体和手部连续遮挡评估

固定原 epoch-83 模型和 checkpoint 的准确率比例 HF/BF 权重，在原始帧对同侧身体与手部区域连续遮挡 5 帧，再用原时间压缩处理。对同一输入配对比较原算术融合、50% 算术加 50% 归一化几何融合、max5 锚点修复及两者组合。完整协议和输入构成见 [固定协议](../correlated_occlusion_protocol_20261106.md)。

## 验证集结果

| 方法 | 干净正确数 / 准确率 | 遮挡正确数 / 准确率 | 遮挡相对原算术 | 修正 / 新错 | 遮挡相对干净的差中差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原算术 | 15537 / 95.2839% | 15390 / 94.3824% | 基线 | 基线 | 基线 |
| 几何混合 | 15593 / 95.6274% | 15456 / 94.7872% | +0.4048pp | 153 / 87 | +0.0613pp |
| max5 算术 | 15536 / 95.2778% | 15424 / 94.5909% | +0.2085pp | 84 / 50 | +0.2146pp |
| max5 + 几何混合 | 15594 / 95.6335% | 15480 / 94.9344% | +0.5519pp | 194 / 104 | +0.2024pp |

差中差是该方法从干净到遮挡的准确率变化，减去原算术从干净到遮挡的准确率变化；避免把已有的干净准确率差异全算成抗遮挡收益。原算术遮挡相对干净下降 0.9015pp。max5 算术在遮挡下净多对 34 条，按完整受试者重采样的 95% 区间为 [+0.0657, +0.3482]pp；其差中差区间为 [+0.0666, +0.3500]pp，20 名受试者中 11 人净改善、4 人净下降。组合的同条件区间为 [+0.3698, +0.8828]pp，差中差区间为 [+0.0676, +0.4196]pp；其干净条件已比原算术多对 57 条。几何混合单独使用的差中差为 +0.0613pp，区间 [-0.0706, +0.3066]pp，不足以支持它单独改善该遮挡条件下的相对抗扰动能力。

训练校准集仅有两个受试者。3,191 条中，遮挡下原算术正确 2,977 条；max5 正确 2,974 条，修正 20 条但新增 23 条错误。max5 在 P009 净多对 9 条，在 P018 净少对 12 条；max5 加几何混合总体净多对 2 条，分别为 +8 和 -6。两名受试者的区间不支持可靠的跨受试者推断。

## 可复核性和边界

全验证 16,306 条均可构造窗口，其中 16,270 条实际同时遮掉身体与手部正分点；其余 36 条的目标手部原本无正分点。全部与可用子集一致。CUDA 前向使用 Inductor 和原模型已存在的 face LocalSTBlock eager 边界；2 条 CPU 与 CUDA 烟测的预测完全一致。完整校准及完整验证的 clean、遮挡和帧掩码哈希均与独立 CPU 预扫描一致，记录见各自 `summary.json`。受试者 bootstrap 使用 20,000 次、种子 20261106，逐人统计与输入哈希见 `subject_bootstrap.json`；完整逐样本配对预测保存在相同目录的 `predictions.csv`。

此前模型、checkpoint 和候选已使用该验证集做过探索，这里不是独立盲测；合成 5 帧相关遮挡不估计真实检测器缺失概率。结果说明固定验证集上的特定遮挡下 max5 净改善，同时存在新增错误与受试者差异，不能推断所有遮挡、动作类别或真实摄像头都改善。该次 clean 结果为 15537 条，历史报告为 15536 条，既有数值审计未确定产生单条差异的原因，不能将其归因于某个单一设置。
