# 预压缩缺失的锚点阈值机制审计

对训练校准分区此前固定抽取的 256 条样本，选出全部 34 条超过 100 帧的序列。对肩髋四锚点，在原始帧按样本名和固定 seed=1729 生成 5% 独立缺失，再使用原有 confidence-weighted 压缩；同一破坏输入分别测试阈值 0.95、0.98 和 max-gap=5。成员、clean 输入、受损输入及 frame mask 的 SHA256 与对应的 34 条配对准确率实验全部相同。

受影响 bin 定义为至少一个有效锚点原始帧被模拟隐藏的压缩 bin；不代表该 bin 输出坐标必然有误。有效输出帧的 clean 正分锚点有 13,602 个，受影响的 834 个中 577 个压缩后为零，257 个仍为正分；另有 12,768 个未受模拟隐藏影响且压缩后为正分的锚点。均为锚点、输出帧、人物三维统计，不是独立样本数量。

| 指标 | 阈值 0.95 | 阈值 0.98 |
|---|---:|---:|
| 受影响且仍为正分的点被标记 | 257/257 (100.00%) | 257/257 (100.00%) |
| 未受影响的正分点被误标记 | 465/12,768 (3.64%) | 6,426/12,768 (50.33%) |
| clean 正分点被标记 | 506/13,602 (3.72%) | 6,864/13,602 (50.46%) |
| 标记的受影响非零点经 max5 恢复正分 | 225/257 (87.55%) | 98/257 (38.13%) |
| 标记的未受影响点经 max5 恢复正分 | 100/465 (21.51%) | 454/6,426 (7.07%) |

恢复正分只表示满足双侧有效端点、缺口不超过 5 帧等插值条件，不代表重建坐标准确。较高阈值标记更多连续点，能够找到合格插值端点的比例相应减少。此前同一 34 条模型推理中，clean 的 0.98+max5 比无修复多错 8 条，与其高误伤率一致；这里的观察不单独证明因果关系。

这只是两个训练校准受试者、34 条长序列、一组固定合成掩码的定向证据。不能据此外推真实检测器遮挡，或宣称 0.95 修复能提高准确率；应在更大的预固定样本上评估 clean 与受损配对结果。

证据为本目录的 `summary.json`、`per_sample.csv` 和选择清单 `../face_pair_anchor_confidence_calibration256_20261105/long_members_precompression_20261106.csv`；复算工具为 `tools/analyze_precompression_threshold_mechanism.py`。
