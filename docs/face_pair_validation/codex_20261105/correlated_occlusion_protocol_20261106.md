# 同侧身体与手部连续遮挡：固定评估协议

目的为测试一个明确的合成压力场景：原始帧中同一人物同侧身体与手部关节点连续缺失，观察现有输入修复与融合的表现。它不估计实际检测器的发生概率，也不代表所有摄像头故障。

固定原 epoch-83 checkpoint，SHA256 `aacf3902d0157c9c33075c828029c876220290710eeed0e879a4ad94782aeee7`；固定 checkpoint 中训练受试者拟合的 HF/BF 按类别准确率比例权重（gamma=1），双头温度均为 1。候选为现有的 max5 锚点修复，以及 50% 原算术融合加 50% 归一化几何融合；全部组合不使用本测试标签调整。评估为冻结推理，不训练。

对每个原始样本，按有效帧的身体点正置信度数选择人物，平局取最小槽位。以样本名及固定 salt 1729 的 SHA256 确定左或右，不看标签、模型预测或另一侧是否更合适。左侧使用点 5、7、9、11、91 至 111，右侧使用点 6、8、10、12、112 至 132（均为零基索引）。仅从该人物身体有至少一个正分且目标侧有至少一个正分的连续 5 个有效原始帧中，以样本名 SHA256 固定选择窗口；只将该窗中上述点原有正置信度的 xy 和 score 置零。自然缺失保留，不改另一人物或非目标点。无有效人物、原序列不足 5 帧或无合格窗口时，样本保持原样并记为不可用；不改选另一侧。该方式按样本固定同一条遮挡路径，避免对不同候选使用不同损伤。每个样本记录人物、侧、起点、可用窗口数和新增遮挡点帧数。

干净与遮挡原始帧均经过原 confidence-weighted 压缩，然后分别运行原始输入和 max5 修复；每次输出原算术和固定几何混合融合预测。max5 只修复不跨无效帧且两端有效、长度不超过 5 个压缩帧的肩髋锚点缺口。该规则依赖未来帧，本测试不测端到端实时延迟。保留成员、压缩后干净及遮挡张量、帧掩码的 SHA256；逐样本记录四种方法两条件预测。

报告全部样本及可用子集的准确率、各方法相对同条件原算术的配对净变化、修正与新增错误、逐受试者变化及可用率；同时报告各方法遮挡相对干净的变化，再减去原算术对应变化（差中差）。按完整受试者有放回重采样 20,000 次，统计样本加权差值的 95% 百分位区间，种子固定为 20261106。只有两名训练校准受试者时，该区间不足以支持跨受试者推断；测试集区间也无法消除验证复用偏差。先运行完整训练校准集作实现检查，结果不用于调整测试参数；如继续运行全验证集，该集此前已参与模型及候选探索，结果是复用数据上的压力测试，不是独立泛化确认。

实时摄像头中整人不通过筛选时会清空识别窗口，因此这里的局部关节点遮挡不能等同于真实摄像头中整人消失后的分类。原始帧级同侧联合遮挡与此前压缩后独立遮挡手或脸、以及逐锚点独立缺口均不同，不能直接将它们的结果解释为同一扰动强度。
