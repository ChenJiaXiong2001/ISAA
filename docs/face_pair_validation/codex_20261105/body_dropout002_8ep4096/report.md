# 身体点 dropout 0.02 的短训配对研究

目标是测试训练时少量身体关键点缺失能否缓解身体关键点缺失的性能损失。固定使用 8 epoch 的 `last.pt`，以训练主体内校准计数计算 γ=1 的 HF/BF 原准确率比例权重。两次训练均从随机初始化开始、强制 `torch.compile`/Inductor，只有身体点 dropout 概率和输出目录不同（对照 0，候选 0.02）。两组均为 seed 17、8 epoch、4096 条验证样本，拟合/校准/验证分别为 3745/351/4096，batch 32、warmup 1、head/fusion loss 权重 0.5/1.0。固定第 8 epoch 是事先选定的比较规则，恰好也是两次训练各自按硬路由指标保存的最佳 epoch；本次对比未从多个 γ=1 验证结果中选点。

身体点 dropout 以每帧每个前 23 个身体点独立缺失的方式模拟，特征在缺失后重新构建。两个模型对同一批次的同一个输入张量及帧掩码执行推理：每种条件的输入、有效点及帧掩码 SHA-256 见 `summary.json`，不依赖两次独立采样碰巧生成相同掩码。同 checkpoint 对自身的 clean、5% 和 10% 三条件自检得失均为 0，见 `selfcheck.log`。配对评价采用相同的验证成员顺序；每个 checkpoint 使用其自身的校准计数，因此 60 类中 43 类的 HF 权重不同，平均绝对差 0.1897、最大 0.75。不能将结果解释为仅改变推理权重或排除训练随机路径及校准权重的影响。

| 输入条件 | 对照 γ=1 Top-1 | 候选 γ=1 Top-1 | 候选减对照 | 配对 bootstrap 95% 区间（pp） |
|---|---:|---:|---:|---:|
| clean | 2347/4096 = 57.2998% | 2204/4096 = 53.8086% | -3.4912pp | [-4.8096, -2.1729] |
| 身体点缺失 5% | 1777/4096 = 43.3838% | 2217/4096 = 54.1260% | +10.7422pp | [9.2285, 12.2559] |
| 身体点缺失 10% | 1248/4096 = 30.4688% | 2070/4096 = 50.5371% | +20.0684pp | [18.5059, 21.6309] |

与各自 clean 相比，5% 缺失造成的准确率下降从 13.9160pp 变为 -0.3174pp，下降量减少 14.2334pp；10% 缺失造成的下降从 26.8311pp 变为 3.2715pp，下降量减少 23.5596pp。配对差中差 95% bootstrap 区间分别为 [12.6465, 15.8203]pp 和 [21.6797, 25.4150]pp，按同一验证样本在两种条件下重采样 20000 次计算。候选在 5% 破坏条件略高于 clean 是该次固定破坏采样的观测结果，不应理解为缺失本身必然有益。

按样本中的被试编号分组，4096 条验证样本覆盖 11 个被试：5% 和 10% 缺失条件下均有 11/11 个被试的候选净正确数增加；clean 条件下 2 人净增加、9 人净减少。这是对当前未收敛短训结果的一致性描述，不能直接外推至完整训练模型。

这是早期短训的显著鲁棒性信号，但 clean 准确率损失明显，且不足以外推到 100 epoch 或说明训练随机性之外的普遍效果。该方向应与更低强度增强、输入修复等方案比较，而不直接宣称优于完整的 95.51% γ=1 模型。两组分别使用自己的训练内校准计数，置信区间只反映当前验证样本的配对抽样，不覆盖不同训练及校准划分的变化。

候选训练状态 completed、无 NaN/Inf，编译范围为身体/手部编码、masked pooling、两分类头与融合，原 face LocalSTBlock 的 eager 边界保留。训练与其他 GPU 实验部分并行，墙钟耗时 675.6 秒不应视为单独运行的速度基准。候选 checkpoint SHA-256 为 `992d1e55e3c889c42c672a7bbeae9ca91b9deee9a81f0af3c60b0b29a3861862`，对照为 `8a0fc6d2ad19ceefc3fe3cfced748d67422fe9b46da86e508df86b3e3d26ea57`。
