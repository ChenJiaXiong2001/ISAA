# HF/BF 原比例加权模型研究备忘录

> 2026-11-06 后续复核：本文记录的是当时的 seed2 实验和判断，并非当前指定 epoch 83 模型的最新结论。手脸几何分支在后续同预算配对短筛中 clean 下降 3.3447pp，当前不支持进入长训；详见 [多方面短训筛选](multiaspect_screen_20261106/report.md)。当前模型的相关遮挡结果见 [同侧遮挡评估](correlated_occlusion_20261106/report.md)。

## 结论

当前最有证据的新增方案是肩髋锚点的有界时间插值。它只应作为合成 anchor-only 缺失条件下的鲁棒性候选，不应作为 clean 准确率提升方案，也不能据此宣称对现实摄像头遮挡具有同等泛化能力。

## 固定模型与口径

所有完整验证结果使用 seed2 从头训练得到的固定 checkpoint，γ=1 原准确率比例权重不变，模型不再训练。训练入口保持随机初始化、强制 `torch.compile`/Inductor，编译失败显式报错；原 face `LocalSTBlock` 的 eager 边界保留。验证中的损坏是合成输入处理，不是新的模型训练结果。

## 其他候选的结论

最新的手到脸几何/运动通道候选在 8 epoch/4096 同协议配对短筛中同时改善 clean 和身体点缺失：前 4096 条上 clean 从 57.2998% 到 59.1309%（+1.8311pp，95% bootstrap [+0.5371,+3.1250]），5% 缺失从 43.6768% 到 50.5371%（+6.8604pp，[+5.4932,+8.2275]），10% 缺失从 30.5664% 到 39.0869%（+8.5205pp，[+7.2021,+9.8389]）。它只改 HF 输入，保留 BF、face 和 gamma=1 融合；这是当前最值得进入完整训练验证的候选。由于仍是 8 epoch/4096 短训，不能把这些百分点外推到 100 epoch，完整训练必须从随机初始化重新开始。

8 epoch 短训中，身体点 dropout=0.005/0.01/0.02 都提高合成身体缺失鲁棒性，但 clean 分别下降约 1.83/1.86/3.49 个百分点，不能外推到完整训练。0.01 是本轮短训的折中候选，不应直接长训或替代原模型。

训练内两受试者交叉筛选排除了温度缩放、动态置信门控、伪计数平滑和归一化名次融合：它们没有稳定的 γ=1 Top-1 提升，部分 NLL 改善也未转化为准确率改善。原概率域 γ=1 方案保持不变。

## 证据边界

所有缺失模式都是人为合成，不能代表真实检测器的低置信度、压缩前缺失、连续遮挡频率或外部摄像头分布。当前数据中压缩前短暂缺失还可能被聚合成低置信度但非零的点，零分插值无法识别。完整结果、逐样本预测、受试者 bootstrap 和可复算脚本保存在 `face_pair_anchor_gap_candidates_validation_20261105/`；综合过程记录在 `research.md`。
