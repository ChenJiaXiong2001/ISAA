# 身体点 dropout 0.005 的短训配对研究

目标是检验比 0.02 更温和的身体点缺失增强能否在 clean 准确率与缺失鲁棒性之间取得更好的折中。固定用训练完成的 epoch 8 `last.pt`，按各 checkpoint 的训练内校准计数计算 γ=1 HF/BF 原准确率比例权重。训练从随机初始化开始，8 epoch、4096 样本、seed 17、batch 32、warmup 1、head/fusion loss 0.5/1.0、强制 `torch.compile`/Inductor；相对对照仅 `joint_dropout_probability` 从 0 改为 0.005，输出目录不同。两组均在 epoch 8 达到各自硬路由最佳。模型选择规则固定为 epoch 8 last checkpoint，没有按 γ=1 验证结果选点。

评估使用与默认对照完全相同的验证成员、同一 batch 输入和 frame mask；每个条件的特征、有效点与帧掩码 SHA-256 与 0.02 实验的输入摘要一致，确保各候选接受相同的缺失模式。每个模型仍使用自身校准计数，60 类中有 38 类 HF 权重不同，平均绝对差 0.1274、最大 0.5。故配对差异包含训练与各自校准权重差异的共同影响，不能归因于单一因素。

| 输入条件 | 对照 γ=1 Top-1 | 候选 γ=1 Top-1 | 候选减对照 | 配对 bootstrap 95% 区间（pp） |
|---|---:|---:|---:|---:|
| clean | 2347/4096 = 57.2998% | 2272/4096 = 55.4688% | -1.8311pp | [-3.1006, -0.5615] |
| 身体点缺失 5% | 1777/4096 = 43.3838% | 2098/4096 = 51.2207% | +7.8369pp | [6.5186, 9.1553] |
| 身体点缺失 10% | 1248/4096 = 30.4688% | 1723/4096 = 42.0654% | +11.5967pp | [10.3027, 12.8906] |

相对各自 clean，5% 身体点缺失造成的下降量减少 9.6680pp（配对差中差 95% CI [8.1299, 11.1816]）；10% 缺失下降量减少 13.4277pp（CI [11.7676, 15.0879]）。置信区间以相同验证样本配对重采样 20000 次计算。按 P 编号分组，验证集覆盖 11 人：两个破坏条件均 11/11 人净增，clean 为 2 人净增、9 人净减。

与同协议的 0.02 候选相比，0.005 把 clean 损失从 3.4912pp 收窄到 1.8311pp；但 5%/10% 破坏条件的净提升由 +10.7422/+20.0684pp 降到 +7.8369/+11.5967pp。当前短训结果显示强度权衡，但模型仅训练 8 epoch、每类样本约 68 条，不能推断完整训练或对 95.51% 全量模型的最终影响。没有启动长训。
