# ISAA accuracy and robustness research checkpoint

本轮研究以 formal epoch-83 `best-face-pair` checkpoint 为基线。checkpoint SHA256 为 `aacf3902d0157c9c33075c828029c876220290710eeed0e879a4ad94782aeee7`，validation manifest SHA256 为 `82fd60410fd04e381c65d3bb9f24f18f7993124ee2581902942fbfb4a2ecddc0`，共 16,306 条样本。

## 当前最优候选

在编译网络前向后，将原有 arithmetic probability pool 与 weighted geometric pool 按 0.5/0.5 混合。模型参数、训练入口和 checkpoint 不变。

| 条件 | 相对 arithmetic | subject bootstrap 95% CI |
| --- | ---: | ---: |
| clean | +0.3557pp | [+0.234, +0.530] |
| point dropout 5% | +0.675pp | [+0.283, +1.136] |
| point dropout 10% | +0.092pp | [-0.330, +0.416] |
| group dropout 5% | +0.497pp | [+0.275, +0.894] |
| group dropout 10% | +0.442pp | [+0.282, +0.716] |

另一组随机掩码复核得到 point 5% +0.932pp、group 5/10% 约 +0.540pp。强度 0.75 和 1.0 在 point 10% 上出现负向，0.25 clean 增益较小，因此当前固定 0.5。

对压缩前 anchor 缺失的 detector-like screen：

- 5% 缺失后，max5 修复再做 geometric fusion：+0.435pp，CI [+0.330, +0.593]；
- 10% 缺失后，同样为 +0.429pp，CI [+0.295, +0.631]。

这支持将 max5 修复用于缺失 anchor 流，再使用 strength 0.5 geometric fusion。缺失掩码为合成协议，validation 在本轮研究中被重复使用。

## 已排除方向

- `score^p` temporal compression：p=0/0.5/1 clean 为 95.28394%，p=1.5/2 仅多 1 个样本（+0.00613pp）。
- 8 epoch scratch hand-face temporal interaction：point/group 鲁棒性明显提高，但 clean 约下降 0.47pp，未通过 clean gate，不进入长训。
- mask-aware derived geometry：仅屏蔽 cross-hand geometry 基本中性；center/scale fallback clean 下降 0.215pp，point dropout 下降约 76/69pp，拒绝训练。
- rank fusion、soft confusion、动态 confidence、loss/KL 和跨 seed geometry 方向没有稳定的全体 Top-1 证据。
