# 全身骨架动作识别研究进展报告

**研究周期：2026年10月19日—11月8日**

## 一、研究目标与阶段概况

本阶段围绕基于全身二维骨架的动作识别展开，重点研究如何利用身体、手部和面部关键点提高动作识别准确率，并改善关键点缺失时的识别稳定性。

近三周的工作主要包括：整理原有模型及对比结果；探索动态选择骨架关键点；建立身体、手部和面部特征融合模型；研究长视频处理、关键点缺失修复和低置信度结果筛查；对多个新增模型和推理方法进行实验比较。

目前，较有依据的候选方法包括：调整两个分支预测结果的融合方式、按视频长度选择时间处理方式，以及对短时间缺失的关键点进行插值修复。新增的“派生几何特征随机屏蔽”训练方案经过完整训练后低于对照模型，已停止继续采用。

## 二、研究背景

本项目使用人体全身二维骨架进行动作识别。每帧骨架包含身体、双手和面部关键点；模型通过关键点位置及其随时间的变化判断动作类别。

全身关键点能够提供比身体骨架更细致的信息，但也带来几个问题：部分关键点可能对某个动作帮助有限；手部或面部可能被遮挡或检测失败；视频长短不同，需要统一输入长度；不同身体部位对不同动作的识别作用也不相同。本阶段研究围绕这些问题展开。

## 三、主要研究内容

### 1. 基础模型整理与动态关键点选择

10月19日前后，整理了原池化模型与单流 CTR-GCN 模型的对比结果，并完善了133个全身关键点的研究报告、模型结构解释和汇报材料。

随后设计了多版动态关键点选择方法：让模型根据输入片段，决定更多关注哪些身体关节、双手关键点组和面部区域。后续版本进一步调整了选择机制、训练中的梯度传递和成本约束，以减少模型选择全部关键点或关闭全部关键点的风险。

目前这些工作已形成模型设计和测试方案，但现有资料不足以证明它已经在独立测试中提高准确率或降低实际采集成本。因此，动态选择仍属于待验证方向。

### 2. 身体、手部与面部特征融合

建立了双分支融合模型：分别利用“手部与面部”以及“身体与面部”的特征进行动作分类，再综合两个分支的预测结果。研究还设置了加入原始二维坐标的对照方案，用来观察坐标表示方式的影响。

这一设计可以分别观察不同身体部位提供的判别信息，也为后续改进分支之间的融合提供基础。不过，融合规则的校准数据主要来自少数受试者，验证集也被多次用于方案筛选，因此现有结果还不能代表对新受试者的最终泛化能力。

### 3. 预测结果融合方式

在保持已训练模型参数不变的情况下，比较了原有预测结果融合方式与加入几何融合后的方式。几何融合可以理解为另一种综合两个分支预测概率的方法；本次将原方法和几何融合结果各占一半。

在包含16,306条样本、20名受试者的验证集上，与原融合方法相比：

| 测试条件 | 准确率变化 |
|---|---:|
| 正常输入 | 提高0.3557个百分点 |
| 随机缺失5%的关键点 | 提高0.675个百分点 |
| 随机缺失10%的关键点 | 提高0.092个百分点 |
| 随机缺失5%的关键点组 | 提高0.497个百分点 |
| 随机缺失10%的关键点组 | 提高0.442个百分点 |

其中，关键点缺失10%时的统计区间包含零，不能认定提升稳定。整体而言，该融合方式值得保留为后续验证的候选方案。

### 4. 不同长度视频的时间处理

动作视频长度不同，直接截取或统一压缩可能丢失动作信息。本阶段测试了按原始视频长度选择处理方式：当视频超过100帧时，采用结合关键点置信度的时间压缩；不超过100帧时不采用该压缩方式。

在当前验证集上，与对照处理方式相比，正常输入的识别准确率提高1.1959个百分点；随机缺失5%和10%关键点时，分别提高1.4780和1.4902个百分点。该策略值得继续研究，但仍需在未参与方案选择的受试者数据上确认效果。

### 5. 关键点缺失与修复

针对骨架检测可能出现的关键点缺失，研究了训练时加入缺失增强，以及推理前对短缺失片段进行插值两种方法。

**缺失增强训练：**在训练过程中模拟关键点缺失。对照实验中，增强模型在正常输入下的准确率为94.1065%，低于对照模型的94.6461%，下降0.5397个百分点；但在时间压缩后身体关键点缺失5%和10%时，分别比对照模型提高2.7045和6.2615个百分点。这表明增强可能改善缺失条件下的稳定性，但需要权衡正常输入时的精度损失。

**短缺失插值：**当缺失位置前后均有有效关键点、缺失间隔不超过5帧且满足有效帧条件时，用前后坐标估计中间位置，不向两端外推。该方法在正常输入下影响很小，准确率下降约0.0123个百分点；在模拟的压缩前关键点缺失5%条件下，准确率提高3.8513个百分点。与前述几何融合结合后，在模拟缺失5%和10%的条件下分别提高约0.435和0.429个百分点。

上述缺失均为人工模拟，尚不能直接说明真实摄像头遮挡和检测失败时会有相同效果。

### 6. 新训练方案与未通过的方向

“派生几何特征随机屏蔽”方案在短轮次筛查中曾显示提升，因此进行了从随机初始化开始的100轮完整训练。该训练完成，最佳结果出现在第87轮，验证准确率为93.8857%。

但在与稳定对照模型逐样本配对比较时，该方案在正常输入下低约0.83个百分点，在关键点缺失5%和10%时分别低约1.86和2.13个百分点。根据完整实验结果，该方案不予保留。

此外，原始坐标、部分几何特征修正、简单时间平滑以及若干预测排序与融合方式，尚未表现出稳定的总体收益，当前暂停继续投入。

### 7. 低置信度结果筛查

研究了利用模型预测置信度安排人工复核：优先检查模型最没有把握的样本。在一次验证实验中，筛出约10%的低置信度样本后，剩余样本的准确率为98.62%，被筛出的样本包含713个错误中的510个。

这说明低置信度有助于集中发现错误，但仍存在置信度高却预测错误的情况，因此它适合作为人工复核的排序依据，不能直接视为自动纠错方法。另一种结合两个分支分歧程度的排序规则，在相同复核数量下发现的错误更少，已排除。

## 四、阶段性结果汇总

| 研究方向 | 阶段结果 | 当前判断 |
|---|---|---|
| 预测结果几何融合 | 正常输入和多种缺失条件下有提升 | 保留，继续验证 |
| 按视频长度处理时间帧 | 当前验证集正常输入提高1.1959个百分点 | 保留，验证新受试者 |
| 短缺失插值修复 | 模拟短时间缺失时有收益，正常输入影响很小 | 保留，验证真实检测场景 |
| 缺失增强训练 | 缺失条件下改善，但正常输入准确率下降 | 继续评估取舍 |
| 动态关键点选择 | 已形成设计与测试方案 | 尚无独立效果结论 |
| 派生几何特征随机屏蔽训练 | 完整训练结果低于对照模型 | 停止采用 |
| 低置信度人工复核 | 错误集中于部分低置信度样本 | 作为复核排序候选 |

## 五、实验可靠性与当前限制

多数比较使用同一 NTU60 跨受试者验证集，该验证集已多次参与研究筛选，因此当前提升可能受到方案选择过程影响。另一数据划分中的复核样本与原验证集有交集，不能称为独立测试。

部分缺失、遮挡和压缩情况由人工模拟；少数动作类别、受试者和长视频的样本量较小，局部结果不能直接推广到所有情况。因此，本报告中的提升应理解为**当前实验条件下的结果**。

## 六、下一阶段工作

1. 固定模型和方案选择规则，使用未参与调参的新受试者数据，复核正常输入与不同缺失条件下的准确率。
2. 在真实摄像头或真实检测失败场景中，验证短缺失插值和时间处理方法。
3. 比较动态关键点选择与使用全部关键点的效果，记录实际保留的关键点数量及识别准确率。
4. 将校准数据与测试数据分开，继续评估低置信度筛查对人工复核的帮助。

**主要依据：**项目中的《近三周研究进展报告》及2026年11月7日研究结论记录。
