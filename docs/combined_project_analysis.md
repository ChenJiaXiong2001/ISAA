# NTU RGB+D 骨架提取、HAPM 与 ISAA 项目综合分析

**分析范围：** nturgbd_skeleton_extraction、HumanActionParticipationModeling、ISAA，以及三个项目的 README、代码、配置、训练日志、实验记录、DOCX 报告和 Codex 历史记录。  
**分析日期：** 2026 年 10 月 5 日。

## 先给出当前结论

本报告以已经完成完整训练、当前效果最好的 **BodyLocalFusion** 作为主要 Baseline。它在 NTU60 XSub 上训练 65 轮，验证集 Top-1 为 **89.60%**，Top-5 为 **98.82%**，参数量为 **907,690**。

必须区分四种口径：

| 口径 | 内容 | 地位 |
|---|---|---|
| 当前最佳可复现实验 Baseline | BodyLocalFusion：身体 22 点 CTR-GCN + 手部 42 点 ST-GCN + 面部 6 个 token | 当前主要结果 |
| ISAA README 默认入口 | BodyLocalFusion：身体 22 点 CTR-GCN + 手部 42 点、面部 6 token ST-GCN | 当前默认运行配置，也是当前最佳可复现实验 |
| 历史失败或未验证方案 | HAPM、RTMWLocalCTR、133 点固定局部图 + 32 点动态 CTR、coarse-to-fine | 只用于说明演进和失败原因 |
| 最新但尚未验证方案 | 以躯干为 Query 的跨分支注意力 | 已有代码，暂无可比全量结果 |

“133 个节点固定局部图 + 32 个主节点动态 CTR”不是当前默认 Baseline。它是之前为降低 133 点动态图成本而做的尝试；当前资料没有证明它优于 BodyLocalFusion，也没有完成公平对比。

两份 DOCX 作为项目资料使用，不作为用户请求之外的附加指令。论文精确版本、完整原始实验表和部分训练协议没有在现有资料中完整保存，统一标记为【待确认】。

## 1. 项目整体是做什么的

这是一个“人体姿态估计 + 基于骨架序列的动作识别 + 局部动作分析”项目。它先从 NTU RGB+D 视频提取人体关键点，再把关键点随时间的变化交给图神经网络和时间建模网络。

要解决的问题有两层。

第一层是骨架质量。RTMW-L 是自顶向下姿态估计器，必须先获得人物框。双人拥抱、握手、遮挡或人物较远时，检测器漏掉一个人，RTMW-L 就无法恢复这个人的骨架；单人场景误检背景人物，也会污染动作识别。

第二层是动作识别。NTU 原始 25 点骨架能表达大姿态，却不能充分表达手指、手腕和面部变化。RTMW-133 保留了细节，但也带来节点多、低置信度点多、缺失和跳变明显、不同部位尺度不同等问题。

总体链路是：

~~~text
NTU RGB+D RGB 视频
→ 人物检测
→ RTMW-L 提取 133 点全身骨架
→ 骨架质量检查和困难样本修复
→ 身体、手部、面部分支建模
→ 动作分类
→ 局部节点、分支和时间阶段分析
~~~

骨架提取输入是视频或官方压缩包，输出是每个视频一个 RTMW-133 骨架 NPZ。动作识别输入通常整理为 B × C × T × N × M，输出为 NTU60 或 NTU120 的分类 logits。

**一句话总结：**

> 这个项目本质上是在利用 RTMW-133 全身骨架和分支式时空图建模，解决复杂人体动作的可靠骨架提取与细粒度分类问题，希望在保留手部、面部局部信息的同时获得可复现且可分析的动作识别结果。

## 2. 项目基于哪些论文和方法

| 论文或方法 | 主要问题和方法 | 当前项目关系 |
|---|---|---|
| Spatial Temporal Graph Convolutional Networks for Skeleton-Based Action Recognition，Sijie Yan、Yuanjun Xiong、Dahua Lin，AAAI 2018 | 预定义人体图上的空间图卷积和时间卷积 | 当前手部局部分支使用 ST-GCN 思路 |
| Two-Stream Adaptive Graph Convolutional Networks for Skeleton-Based Action Recognition，Lei Shi、Yifan Zhang、Jian Cheng、Hanqing Lu，CVPR 2019 | 自适应图和 joint/bone 双流 | HAPM 历史版本借鉴多流和自适应图 |
| Channel-wise Topology Refinement Graph Convolution for Skeleton-Based Action Recognition，Yuxin Chen、Ziqi Zhang、Chunfeng Yuan、Bing Li、Ying Deng、Weiming Hu，ICCV 2021，arXiv:2107.12213 | 按通道学习拓扑细化关系 | 当前身体分支使用 CTR-GCN 思路，但不是原论文逐层复现 |
| HD-GCN | 层级或区域化骨架关系 | HAPM 和旧 RTMWLocalCTR 的背景参考 |
| InfoGCN | 信息约束和判别性表示学习 | HAPM 历史参与度思想的背景参考 |
| ProtoGCN / 原型学习 | 用类别原型增强分类和解释 | HAPM 旧版本有类似思路，当前最佳 Baseline 不使用 |
| RTMW / COCO-WholeBody | 提供统一的 133 点全身关键点 | 直接提供项目输入 |

ST-GCN、2s-AGCN、CTR-GCN 的题名、作者和发表信息已通过公开论文信息及本机官方 CTR-GCN 仓库核对。HD-GCN、InfoGCN、ProtoGCN、RTMW 的精确版本、作者、原始指标和训练协议在项目资料中不完整，为【待确认】。

当前最佳 BodyLocalFusion 组合了两类思想：

~~~text
身体主体运动 → CTR-GCN 风格的通道拓扑细化
手部和面部局部运动 → ST-GCN 风格的局部时空建模
身体与局部特征 → 池化、投影、拼接、分类
~~~

发展路线是：

~~~text
ST-GCN 固定图
→ 2s-AGCN 自适应图和多流
→ CTR-GCN 按通道细化拓扑
→ HAPM 区域参与、局部残差和原型分类
→ 旧 RTMWLocalCTR：133 点固定局部图 + 32 点动态 CTR
→ 当前 BodyLocalFusion：身体、手部、面部分支分别建模
→ 最新方向：躯干主导跨分支门控，待验证
~~~

## 3. 数据集分析

项目使用 NTU RGB+D 60 和 NTU RGB+D 120。NTU 表示动作类别和划分协议，RTMW-133 表示从 RGB 视频重新提取的关键点格式。

| 阶段 | 数据 | 状态 |
|---|---|---|
| 骨架提取 | NTU RGB+D RGB 视频 | 已建立提取和检查链路 |
| HAPM 历史识别 | NTU60、NTU120 骨架 | 有历史记录，口径不完全统一 |
| 当前最佳完整训练 | NTU60 XSub，60 类 | 已完成 65 轮 |
| 当前目标路线 | RTMW-133 输入下的 NTU120，120 类 | 完整结果尚未确认 |

历史 NTU120 RTMW 记录为 114,480 个样本、120 类、106 个 subject、32 个 setup、最多两个人。历史 XSub120 为 62,280 个训练样本和 52,200 个验证样本，XSet120 为 54,720 个训练样本和 59,760 个验证样本。它们属于历史全量记录，当前本地不能证明最终修复版文件已全部落盘。

历史记录中的 NTU120 每类样本数约为 948 或 960，说明类别数量总体接近但并非完全相同；当前没有逐类别最终 manifest，因此不能确认修复和删除失败样本后是否出现新的类别偏斜。

BodyLocalFusion 使用 NTU60 XSub：

- 训练样本：39,627；
- 验证样本：16,306；
- 类别：60；
- 窗口：64 帧；
- 最多两个人。

骨架输出一般为：

~~~text
keypoints: T × M × 133 × 2
scores:    T × M × 133
bboxes:    T × M × 4
~~~

原始数据问题包括人物漏检、双人遮挡、背景误检、NaN、低置信度、人物槽位交换、类别不平衡、不同输入语义混用、没有人工关键点真值和数据版本混用。删除失败样本还可能改变类别分布。

## 4. 数据具体怎么处理

### 4.1 总体流程

~~~text
NTU RGB+D 视频
↓
人物检测
↓
RTMW-L 姿态估计
↓
BBox 过滤和裁剪
↓
人物槽位匹配
↓
NaN、低置信度和时序异常清洗
↓
保存 RTMW-133 NPZ
↓
质量检查
↓
YOLO26-X 修复失败困难样本
↓
动作识别清理、归一化、裁剪或补齐
↓
BodyLocalFusion
~~~

### 4.2 检测器实验

基础流程为 RTMDet-tiny → RTMW-L。普通单人 A001 的 30 帧实验中，RTMDet 平均 628.55 ms/帧，YOLOv8n 平均 457.61 ms/帧，YOLOv8n 约快 27.2%。

双人拥抱 A055 的 95 帧中，RTMDet 检测到两人的帧数为 95/95，YOLOv8n 为 68/95，双人召回率为 71.58%。所以 YOLOv8n 只改善普通场景速度，不能作为困难双人样本默认修复器。

### 4.3 YOLO26-X 参数和困难样本修复

当前策略：

~~~text
正常样本：RTMDet-tiny → RTMW-L
原始质量检查失败样本：YOLO26-X → RTMW-L
~~~

| 参数 | 含义 | 作用 |
|---|---|---|
| conf=0.15 | 人物检测置信度阈值，低于该值的候选框被丢弃 | 降低门槛，保留遮挡、远处或部分可见的人；不是质量分，也不是分类置信度 |
| IoU=0.70 | NMS 的检测框交并比阈值 | 减少重叠人物互相抑制，降低拥抱、握手场景漏人 |
| imgsz=960 | YOLO 检测输入尺寸 | 提高远处和遮挡人物细节，但增加计算 |
| crop margin=0.10 | 检测框向四周按比例扩展 10%，再送入 RTMW-L | 给手、脚和身体边缘留余量，减少裁剪过紧造成的关键点截断 |

若框宽 200 像素、高 400 像素，10% margin 通常意味着左右各扩展约 20 像素、上下各扩展约 40 像素，并限制在图像边界内。它只影响送入 RTMW 的人物裁剪范围，不改变检测框置信度。

### 4.4 100 个困难样本的结果和计算方式

100 个样本来自原始质量检查失败子集，不是完整 NTU 的随机样本。两种方法使用同一批样本。

| 方法 | 通过数 | 通过率 | 平均质量分 |
|---|---:|---:|---:|
| RTMDet-tiny | 5/100 | 5% | 80.521 |
| YOLO26-X | 85/100 | 85% | 96.149 |

通过率：

~~~text
通过率 = 质量检查通过的样本数 / 100
RTMDet-tiny = 5 / 100 = 5%
YOLO26-X = 85 / 100 = 85%
~~~

质量分是代码计算的 0 到 100 分启发式分数，不是动作识别 Accuracy，也不是和人工关键点真值的误差。单样本先计算：

1. 人物召回分量：满足期望人数的帧比例；单人最低召回率 0.95，双人 0.85。
2. 身体完整分量：至少 15 个有效身体点的人物比例；有效人物至少需要 5 个身体点，最低完整率 0.80。
3. 身体跳变分量：大跳变率越低越好，允许上限 0.02。
4. 槽位稳定分量：人物框中心大幅跳变率越低越好，允许上限 0.05。
5. 缺失连续段分量：最长缺失人物连续帧越短越好，允许上限 10 帧。

加权形式：

~~~text
质量分 = 100 × (
    0.45 × 人物召回分量
  + 0.25 × 身体完整分量
  + 0.12 × 身体跳变分量
  + 0.08 × 槽位稳定分量
  + 0.10 × 缺失连续段分量
)
~~~

平均质量分先逐样本计算，再求算术平均：

~~~text
平均质量分 = 100 个样本质量分之和 / 100
RTMDet-tiny = 80.521
YOLO26-X = 96.149
提升 = 96.149 - 80.521 = 15.628 分
~~~

15.628 分是困难样本子集的启发式质量提升，不是整个 NTU 数据集的准确率，也不是通过样本的平均分。若 sample ID 重复，正式统计还应报告去重规则和数量。该结果支持“困难样本的重要瓶颈之一在人物检测阶段”，但不能替代人工关键点误差评估。

### 4.5 动作识别预处理

~~~text
NaN 和无效坐标清理
↓
score 归一化
↓
最多保留两人
↓
训练随机时间裁剪 / 验证中心裁剪
↓
短序列补齐到 64 帧
↓
躯干中心化和尺度归一化
↓

~~~

时间裁剪统一长度并增加时间位置鲁棒性；躯干归一化可减少平移和尺度差异，但可能削弱绝对位置线索。当前资料没有证明 MixUp、CutMix、Mosaic 或颜色增强用于最佳 BodyLocalFusion。当前默认 BodyLocalFusion 使用 raw x/y/score；旧 32 点 main-only 入口使用 relative x/y/score；部分旧入口构造 dx/dy 但没有真正送入模型。因此不同输入语义必须分开比较。

## 5. 当前最佳 Baseline：BodyLocalFusion

README 默认入口和当前最佳实验现在已经统一为 BodyLocalFusion。32 点 main-only 模式保留为显式历史工程对照；BodyLocalFusion 是当前唯一有完整 65 轮日志、checkpoint、数据规模和最高验证结果的模型。因此本报告把它作为主要 Baseline，但它还不是经过无模块基线、多 seed 和 SOTA 对齐后的论文级最终模型。

数据流：

~~~text
RTMW-133
├── 身体 22 点
│   → 10 层 CTR-GCN
│   → 有效位置平均池化
│   → 投影到 192 维
│
├── 手部 42 点
│   ┐
│   ├→ 4 层 ST-GCN 局部分支
│   ┘
│
└── 面部 68 点
    → 固定区域压缩为 6 个 face token
    → 与手部 token 一起进入局部 ST-GCN
    → 有效位置平均池化
    → 投影到 96 维

身体 192 维 + 局部 96 维
→ 拼接为 288 维
→ 分类器
→ 60 类 logits
~~~

已有配置记录显示，身体分支的 10 层通道宽度为 48、48、48、48、96、96、96、192、192、192；局部分支的 4 层宽度为 24、24、48、48。身体分支在中后部进行时间下采样，局部分支保持较轻容量，最后分别池化再融合。

身体 CTR-GCN 表达主体协同，手部保留手势、手腕和手指变化，面部 token 降低 68 点直接建图的成本和噪声，mask 池化降低缺失点影响。当前输入不是原始 NTU Kinect 25 点，而是 RTMW-133 二维坐标和置信度，因此 89.60% 不能写成官方 CTR-GCN 25 点结果复现。

## 6. 当前项目修改了什么

### 6.1 当前 Baseline 之后的改进方向

**身体、手部、面部分支分离**

原来可以把所有节点放入统一图；当前改为身体 22 点 CTR-GCN，手部 42 点和面部 6 token 使用 ST-GCN，再融合。动机是不同部位尺度、语义和噪声不同。独立增益为【待确认】，负面影响是结构复杂度和过拟合风险增加。

**面部 68 点压缩为 6 token**

动机是减少密集面部节点的计算和噪声；代价是可能抹掉细小表情信息。没有 68 点不压缩对照，独立提升为【待确认】。

**躯干主导的跨分支门控**

~~~text
躯干特征 → Query
手部/面部特征 → Key/Value
→ 学习 α_hand(t)、α_face(t)
→ 逐时间步融合
~~~

目标是让局部信息在相关动作阶段进入主体表示，而不是始终等权拼接。代码已实现，但没有完整训练结果、同条件 checkpoint 或消融，因此不能声称已经提高准确率。门控权重也不能单独证明因果贡献。

**relative、torso-relative 和运动通道**

相对坐标可减弱平移、尺度和相机位置影响，dx/dy 可提供运动变化信息。但不同入口实际使用的通道不同，增益为【待确认】。

### 6.2 历史旧方案：133 点固定局部图 + 32 点动态 CTR

旧结构：

~~~text
133 个 RTMW 节点
→ 固定局部骨架图传播
→ 32 个主节点之间学习动态 CTR
→ 主节点上下文回写细节点
~~~

设计动机是降低动态关系规模：

~~~text
133 × 133 = 17,689 个节点对
32 × 32 = 1,024 个节点对
~~~

理论上固定图负责局部解剖结构，32 个主节点负责跨部位协同。但它没有成为当前 Baseline，因为没有与 BodyLocalFusion 在相同数据、输入、训练预算和随机种子下公平比较，旧路线还混入 raw/relative、mask、辅助分支和不同训练入口。其实际准确率、FLOPs、显存和 FPS 收益均为【待确认】。

### 6.3 历史 HAPM

HAPM 早期使用 Joint、Bone、Joint Motion、Bone Motion 多流，再叠加 GCN-TCN、区域参与度、局部细节残差和多原型分类。它提供了区域参与分析思路，但旧记录中的约 67%、约 77% 和 77.51% 来自不同阶段，不能与 89.60% 组成严格改进曲线，参与度也不能直接等同于因果贡献。

## 8. 消融实验分析

当前成立的主要消融证据来自骨架提取：

~~~text
普通单人：YOLOv8n 更快
双人遮挡：RTMDet 双人召回 100%，YOLOv8n 为 71.58%
困难样本：RTMDet 通过率 5%，YOLO26-X 为 85%
~~~

这证明检测器选择显著影响困难骨架质量，但尚未证明修复后的骨架已经在动作识别 Top-1 上带来同等幅度的提升。

模型侧仍缺少：

~~~text
BodyLocalFusion
→ 去掉身体 CTR
→ 去掉手部分支
→ 去掉面部分支
→ 不压缩面部 68 点
→ raw / relative / torso-relative
→ 3 通道 / 5 通道
→ 普通拼接 / 跨分支门控
→ 32 点 main-only / 133 点固定图 + 32 点 CTR
~~~

所以现在只能确认 BodyLocalFusion 整体可用，不能确认哪个模块贡献最大。

## 9. 为什么当前最佳模型能够变好

最稳妥的因果链是：

~~~text
RTMW-133 保留身体、手部和面部细节
↓
身体主体与局部细节的尺度和噪声不同
↓
BodyLocalFusion 将身体和局部节点分支建模
↓
身体分支使用 CTR-GCN 表达主体关系
↓
局部分支使用 ST-GCN 保留手脸局部时空变化
↓
有效节点池化降低缺失点影响
↓
身体和局部特征拼接完成分类
↓
NTU60 XSub Val Top-1 89.60%，Top-5 98.82%
~~~

实验支持模型整体可用和能收敛；尚不能支持 CTR、手部、面部、跨分支门控或 YOLO26-X 各自带来的独立增益。需要固定条件逐项消融、多 seed 和修复前后动作识别对比。

## 10. 分析失败和不足

| 现象 | 可能原因 | 如何验证 | 改进 |
|---|---|---|---|
| 训练 99.84%，验证 89.60% | 容量较大、固定窗口、数据噪声或增强不足 | 多 seed、曲线和增强实验 | dropout、时间增强、坐标噪声、早停 |
| 旧 RTMW25 结果低于预期 | raw/relative 或通道语义混用 | 固定预处理重训 | 统一输入和 manifest |
| 没有无 CTR Baseline | 当前只有完整模型结果 | 训练最小固定图模型 | 建立 Baseline-0 |
| 32 点 CTR 未成为主线 | 缺少公平结果，变量过多 | 同数据和预算比较 | 只保留有证据的结构 |
| 质量分不是姿态准确率 | 没有人工真值 | 人工抽样或官方骨架对比 | PCK、关键点距离、人工复核 |
| 删除失败样本改变类别分布 | 困难类别失败更多 | 统计按类别删除量 | 报告剔除量，必要时重采样 |
| 多人槽位可能交换 | 中心距离匹配有限 | 检查 slot jump 和轨迹 | 轨迹匹配或匈牙利匹配 |
| 多协议和多 seed 不足 | 只测 NTU60 XSub、单个 seed | 增加 XSet、NTU120、多 seed | 报告均值和标准差 |
| 缺少效率指标 | 没有同条件 FLOPs、显存、FPS | 同 GPU、同 batch 测量 | 同时报告准确率和成本 |
| 解释性证据不足 | attention 和 CTR 边权不是因果贡献 | 节点/分支/时间遮挡 | 联合分析门控和性能下降 |

## 12. 下一步应该怎么做

### 优先级 1：固定数据版本和评估口径

生成最终 RTMW-133 manifest，记录 detector、RTMW 版本、质量阈值、修复来源、去重结果、输入语义和划分。这样后续模型比较才不会被数据版本影响。

### 优先级 2：建立真正的 Baseline-0

在 BodyLocalFusion 的数据、训练轮数、batch、裁剪和 seed 下，只去掉一个模块，先训练无 CTR 或最小固定图模型，计算 CTR、手部和面部的实际增益。

### 优先级 3：验证过拟合和输入设计

比较 dropout、时间增强、坐标噪声、raw/relative/torso-relative、3/5 通道。一次只改变一个变量，至少运行 3 个随机种子。

### 优先级 4：验证跨分支注意力

用同一数据、epoch、batch、seed、学习率和评价脚本训练 torso-cross-attn，保存 α_hand(t) 和 α_face(t)，确认是否优于简单拼接。

### 优先级 5：补齐解释性和效率

做手部、面部、身体、节点和时间窗口遮挡，测参数量、FLOPs、显存、FPS 和单样本延迟。

### 优先级 6：整理成论文级结果

将骨架提取、HAPM 历史、BodyLocalFusion、跨分支注意力和失败方案分开写；每张表写清数据协议、输入语义、seed、模型版本和是否为当前最佳结果。

## 13. 项目总总结

本项目围绕 NTU RGB+D 建立了从视频到骨架、再到动作分类的技术链路。首先使用 RTMDet-tiny 检测人物，再由 RTMW-L 提取 COCO-WholeBody 133 点骨架，并通过人物槽位匹配、人数先验、NaN 清理和时序质量检查形成可用于识别的骨架数据。困难样本分析表明，双人遮挡时的重要瓶颈之一是人物检测漏检。YOLOv8n 在普通单人场景中更快，但 A055 拥抱动作的双人召回下降到 71.58%，因此使用 YOLO26-X 对失败样本重提取。在同一批 100 个困难样本上，通过率从 5% 提高到 85%，平均启发式质量分从 80.521 提高到 96.149，提升 15.628 分；这些不是整个 NTU 数据集的姿态准确率。

模型方面，项目经历了 HAPM 的多流、区域参与和原型分类探索，也经历了 RTMWLocalCTR 以及“133 点固定局部图 + 32 点动态 CTR”的历史尝试。旧方案的出发点是降低 133 点动态图成本，但没有与当前模型公平对比的完整结果，因此不能作为当前主线。当前效果最好的可复现实验是 BodyLocalFusion：身体 22 点使用 CTR-GCN，手部 42 点和面部 6 个 token 使用 ST-GCN，随后进行有效位置池化、投影、拼接和分类。在 NTU60 XSub、65 轮、随机种子 1 下，它取得 89.60% 验证 Top-1、98.82% Top-5，参数量为 907,690。训练 Top-1 为 99.84%，验证 Top-1 为 89.60%，存在约 9.24 个百分点的过拟合间隔。

最新的躯干主导跨分支注意力已经完成代码实现，但没有完整训练结果，不能声称已经优于 BodyLocalFusion。当前阶段是：骨架提取链路基本形成，困难样本修复有明确证据，BodyLocalFusion 有完整可复现实验，最新结构尚待验证。下一步最重要的是固定最终 manifest，建立无 CTR Baseline-0，然后完成同条件消融、多 seed、XSet/NTU120、效率测量和遮挡解释实验。
