# 项目目录与三端同步

## 目录用途

| 位置 | 内容 | 同步方式 |
|---|---|---|
| `isaa/` | 数据处理、模型、训练实现 | Git |
| `configs/` | 模型和实验配置 | Git |
| 根目录 `train_*.py`、`main.py` | 保留的训练入口 | Git |
| `tools/` | 评估、服务器启动、摄像头及报告生成工具 | Git，排除 node_modules |
| `tests/` | 回归和集成检查 | Git |
| `experiments/` | 独立实验脚本、协议、研究记录 | Git；历史 code/source 快照保留原处 |
| `docs/` | 使用说明、研究记录及本地报告 | 说明和脚本进 Git；现有证据附件保留原处 |
| `data/`、`outputs/`、`runtime/` | 数据、训练结果、运行权重和部署缓存 | 各机器保留，单独按需传输 |
| `.sync-work/`、`.codex-backups/` | 同步前备份和审计文件 | 各机器保留，不进 Git |
| `.ppt_*`、`.chart-data-*`、`tmp_*` 等 | 报告构建缓存、文献抓取临时文件 | 忽略并保留原处 |

## 2026-11-15 整理原则

以本地已提交历史和较完整的活动代码为基础，合入服务器独有实验脚本。
11 个同名差异经过检查：数据处理、face-pair 训练和通用训练的差异主要是排版；
保留本地额外的评估参数、摄像头锚点修复，以及已记录限制的手部编译实现。
服务器的旧版同名代码、根目录散落副本和冻结训练代码快照保留在原机器及同步前备份中。
本地原有的 AutoDL 编排脚本及两份状态说明删除状态纳入本次快照，旧内容可从 Git 历史和备份恢复。
本次不改模型算法、训练参数或编译边界，不启动训练。

原始 CTR-GCN 与 SkeleT-CTRGCN 继续分别命名；训练的强制编译要求以 `AGENTS.md` 为准。

## 后续同步

先分别检查两端 `git status` 和运行任务，提交或备份工作区改动，再执行 `git fetch` 和正常合并。
工作区干净时使用 `git pull --ff-only origin master` 更新；提交检查通过后正常 `git push origin master`。
禁止用强制推送、清空目录或覆盖整个实验目录来处理差异。
新增权重、大型结果和本机路径不要混入源代码提交；需要发布的报告附件单独明确选择。

本次具体文件清单、冲突决策及同步前源码归档保存在本地 `.sync-work/`，
服务器另保留 `.codex-backups/sync-20261115/`。
