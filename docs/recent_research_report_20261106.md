# 近三周研究进展报告

**统计范围：2026-10-17 至 2026-11-06**  
**项目：ISAA 全身二维骨架动作识别**

## 1. 总体结论

近三周工作从单一模型精度比较，转向三个更具体的问题：

1. 如何在 133 节点全身骨架上动态选择输入，减少冗余并保持动作判别能力；
2. 双人手部、面部与身体信息如何融合，以及模型在输入缺失、遮挡和时间压缩下是否稳定；
3. 如何利用分支置信度安排人工复核，而不是简单改变自动预测结果。

目前最可靠的结果是：在训练阶段加入点/分组缺失增强的 p10 模型，clean 准确率略低于 canonical baseline，但在合成缺失条件下明显更稳，尤其是压缩后身体点缺失。面部/手部双头融合、动态输入门控和选择性预测已经形成可复现实验框架，但仍需要独立测试集或新的受试者验证。部分筛查结果明确排除了当前候选规则，避免继续投入 GPU。

## 2. 研究主线与方法进展

### 2.1 全身骨架输入选择

基于已有 100 帧 confidence-weighted pooled baseline，连续完成 v3、v4、v5 三代输入条件门控设计。

- v3 对 14 个身体关节和 20 组双手对应点进行片段级动态路由；保留 68 个面部点作为固定必要输入。
- v4 增加 6 个面部 token，共 40 个门，并修复关闭节点后的不可导梯度问题；门控采用随机二值前向和 straight-through 梯度。
- v5 针对 v4 的全开/全关塌缩风险，取消全开下限，改用归一化期望成本、LayerNorm、logit 限制和更低的路由学习率，并把全关诊断提前到路由启动阶段。

这些版本都从随机初始化训练，保留旧模型、双手距离/方向特征和旧入口。训练入口统一强制 `torch.compile`，编译失败直接报错；新增路由、门控、池化和融合模块均纳入编译，只有原有 Face `LocalSTBlock` eager 边界保留。当前文档记录的是设计和验证协议，不能据此宣称动态选点已经提高准确率或降低真实采集/训练成本。

### 2.2 双人手部/面部关系融合

新增 `best-face-pair` 及 raw-XY 变体。模型共享 Body CTR-GCN、左右手 CTR-GCN 和 Face ST-GCN 编码器，再分别建立 Hand–Face 与 Body–Face 分类头；每个头接受独立交叉熵，最终按训练校准集得到的类别级路由进行概率融合。新增 raw-XY 变体在手部和面部的 torso-relative 坐标之外加入原始坐标，作为坐标表示消融。

该路线的优点是保留了单流 baseline，并能独立观察身体、手部和面部证据；风险是路由校准只来自 P009/P018 等少量训练校准受试者，验证集也已被反复用于研究，当前结果不能视为盲测泛化结论。

### 2.3 缺失与遮挡鲁棒性

建立了两类验证：训练增强模型的配对验证，以及时间压缩/遮挡口径审计。

- canonical baseline 与 p10 缺失增强模型在同一输入和掩码下配对评估。p10 clean 为 **94.1065%**，baseline 为 **94.6461%**，clean 下降 **0.5397 个百分点**；但压缩后身体点缺失 5%/10% 时，p10 相对 baseline 分别提升 **2.7045/6.2615 个百分点**，受试者 bootstrap 区间均为正。
- 原帧锚点缺失 5%/10% 时，p10 相对 baseline 提升 **0.0675/1.1223 个百分点**；压缩后分组缺失 5%/10% 时提升 **0.0920/1.1284 个百分点**。
- 时间压缩审计显示，短片段、101–197 帧片段和 200–281 帧片段的遮挡影响不同；最长片段样本仅 27 条，不能将差异归因于压缩本身。
- 置信度加权三帧平滑在固定合成遮挡代理上没有降低受影响点的位移，且会增加其他点的输入变化，因此暂不建议投入 GPU。

这说明缺失增强值得继续研究，但 p10 clean 损失和动作类别差异仍需在独立受试者、固定 checkpoint 选择规则下复核。合成缺失不等于真实摄像头故障。

## 3. 置信度、校准与选择性预测

### 3.1 几何融合权重稳定性

对 epoch-83 的 3191 条训练校准片段进行按受试者留一筛查。加入一个伪计数后，P009 正确数保持 674/708，P018 从 2342/2483 变为 2341/2483，NLL 也没有改善。原始 HF 类别权重在两名受试者之间平均差约 0.0549，说明校准样本仍偏少，暂不替换原始权重。

### 3.2 低置信度拒识

冻结 HF/BF checkpoint 后，用训练校准集确定最大融合概率阈值，再在 16,306 条验证样本上评估：

| 拒识比例 | 覆盖率 | 接受样本准确率 | 捕获错误 |
|---:|---:|---:|---:|
| 5% | 94.98% | 97.70% | 356/713 |
| 10% | 90.52% | 98.62% | 510/713 |

低置信度可以减少人工复核范围并富集错误，但高置信错误仍然存在，且 A011、P036 等类别/受试者差异明显。因此它适合被视为复核调度信号，不足以作为自动纠错机制。

### 3.3 分支分歧排序

测试了 `融合最大概率 × (1-JSD)` 的固定排序规则。相同复核预算下，5% 档比最大概率基线少捕获 115 个错误，10% 档少捕获 102 个错误；受试者聚类区间也整体偏负。因此当前简单 JSD 分歧排序应淘汰。双头不一致确实富集错误，但“分歧”本身不能替代校准后的最大概率。

## 4. 近期实验结果汇总

| 方向 | 当前证据 | 判断 |
|---|---|---|
| p10 缺失增强 | clean -0.54pp；多种缺失条件明显提升，身体点缺失最大 | 值得继续，优先做独立测试 |
| 时间平滑 | 受影响点位移未下降，其他点变化增加 | 当前规则停止 |
| 人物槽位占用校准 | 低占用槽位理论最大净收益仅 0.1254pp，且动作组严重混杂 | 不支持删除人物槽位 |
| 几何融合权重平滑 | 留一结果无改善 | 保留原权重 |
| 最大概率拒识 | 10% 拒识捕获约 71.6% 错误，接受准确率 98.62% | 可作为复核调度候选 |
| JSD 分歧拒识 | 同预算劣于最大概率 | 淘汰当前规则 |
| 动态输入门控 v3–v5 | 已完成机制迭代和编译/梯度测试，暂无独立精度结论 | 继续验证，不能提前下结论 |

## 5. 工程与可复现性

- 新训练入口默认强制 `torch.compile`，拒绝 `--no-compile`；编译失败或重编译超限直接失败。
- CUDA 检查工具覆盖前向、反向、优化器更新、有限梯度和编译范围证据；CPU 单测覆盖门控梯度恢复、缺失输入、数值稳定性和审计脚本。
- 实验保存模型、输入/成员清单哈希、逐样本预测、分层汇总和协议文件，便于复算。
- 当前工作区存在大量未提交实验文件及删除/修改状态；本报告只做归纳，不改变这些实验结果或历史入口。

## 6. 目前限制

1. 许多验证使用同一 NTU60 XSub 验证集反复筛查，区间不能修正模型选择偏差。
2. 校准主要来自 P009/P018，P007 样本量较大，会影响总体样本加权统计。
3. 缺失、遮挡和时间压缩均为合成代理，尚未证明与真实摄像头故障一致。
4. 部分类别和长序列分层样本很少，不能把局部增益推广为整体规律。
5. 动态门控设计文档完整，但没有在本报告中把“设计目标”当成“已验证收益”。

## 7. 下一阶段建议

1. 固定 checkpoint 选择规则，在未参与门控/增强调参的新受试者上复核 p10 鲁棒性，并同时报告 clean 与多种缺失条件。
2. 对 v5 只保留硬门二值验证、全开对照和独立测试，重点检查是否真正减少输入而不牺牲动作类别覆盖。
3. 将最大概率拒识作为基线，另行设计校准集与测试集完全分离的复核调度实验；暂不继续 JSD 乘法规则。
4. 对 face-pair/raw-XY 变体补充跨受试者和类别分层结果，再决定是否进入正式模型比较。
