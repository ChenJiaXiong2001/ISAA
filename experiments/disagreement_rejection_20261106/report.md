# 分支分歧用于拒识的筛查

结论：在既定的两个复核预算下，将 HF/BF 分歧加入排序的这条固定规则，
捕获的错误少于仅按融合最大概率排序，不建议采用。该测试使用 checkpoint
实际保存的准确率比例权重；所有样本的分类准确率没有因拒识而改变。

双头输出先经 softmax，计算归一化 Jensen-Shannon 散度 JSD，再令候选
得分为 `融合最大概率 * (1 - JSD)`；JSD 在这里按 ln(2) 归一化。两档阈值
分别取两名训练校准受试者共 3191 条样本候选得分的 5% 和 10% 分位数，
基线阈值用同一校准缓存的融合最大概率分位数确定。类别权重、模型和规则
均固定，未使用验证标签选择阈值或排序。原始验证 logits 缓存共 16306 条。

| 比较 | 复核数 | 覆盖率 | 基线捕获错误 | 候选捕获错误 | 基线 / 候选接受准确率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 校准 5% 阈值，基线 | 818 | 94.9834% | 356 | - | 97.6950% |
| 校准 5% 阈值，候选 | 900 | 94.4806% | - | 266 | 97.0985% |
| 同数匹配，候选 | 818 | 94.9834% | 356 | 241 | 97.6950% / 96.9525% |
| 校准 10% 阈值，基线 | 1546 | 90.5188% | 510 | - | 98.6247% |
| 校准 10% 阈值，候选 | 1549 | 90.5004% | - | 408 | 97.9332% |
| 同数匹配，候选 | 1546 | 90.5188% | 510 | 408 | 98.6247% / 97.9336% |

同数匹配仅按验证集无标签得分排序，取与基线完全相同的复核数量，适合
离线比较但不是固定的逐条上线阈值。候选分别净少捕获 115 和 102 个错误；
按 20 名受试者聚类重采样，捕获数差占全体验证样本的 95% 区间分别为
[-1.0374, -0.5210] 和 [-0.8293, -0.5287] 个百分点。5% 档 19 人净下降、
1 人净改善；10% 档 19 人净下降、1 人持平。受试者 P007 样本多，分别净少
捕获 30 和 29 个错误，但其余多数受试者方向相同。

双头 argmax 不一致的 2387 条包含了 713 个融合错误中的 510 条，另外 203 个
错误发生在双头一致时。双头分歧确实富集错误，并不意味着这个简单乘法排序
胜过最大概率：5% 匹配下候选新增捕获 47 个原本通过的错误，同时放过基线已
捕获的 162 个错误；正确样本也被调换。该结果只排除这里固定的一条规则，
不能推广到所有可能的分歧指标或模型。

## 权重与核验

两份缓存都记录相同 epoch-83 checkpoint SHA256，成员顺序摘要与对应校准、
验证清单一致。校准缓存重算的逐类权重与 checkpoint 保存计数有两类差异：

| 类别 | HF 正确数 | BF 缓存 / 保存正确数 | HF 权重缓存 / 保存 |
| --- | ---: | ---: | ---: |
| A011 | 49 | 45 / 44 | 0.521277 / 0.526882 |
| A012 | 40 | 38 / 39 | 0.512821 / 0.506329 |

类别总数和 HF 正确数完全一致，差异原因目前未确定。早期缓存权重结果保留
在 `result/`；本报告使用 `disagreement_frozen/` 的 checkpoint 权重结果。
`audit.py` 用独立的 PyTorch log-softmax 与熵公式复算逐样本分数、阈值及
20 人和 60 类统计，结果一致；逐项差异见 `disagreement_frozen_audit.json`。
同目录 `protocol.md` 和 `analyze.py` 可复算固定规则，逐样本 CSV 和汇总 JSON
保留在对应输出目录。

之前几何融合的主要完整验证 `evaluate_cuda.py` 和缓存验证
`evaluate_validation.py` 均从 checkpoint 读取保存计数，不受本次缓存重算
权重差异影响；几何方法最初的两受试者留一筛选使用每折重新拟合的权重，
它与固定权重是不同的筛选协议。这里的验证集已反复探索，置信区间不能修正
方法选择偏差；阈值来自两个受试者，也没有真实遮挡下的分数或复核成本数据。
